# 動詞の活用と正かなづかひ

`segzify`は、熟語置換の後、正字變換と旣存のかな置換の前に、動詞の活用形を正かなづかひへ正規化する。これは口語の表記の變換であり、文語への翻譯ではない。

本文は`segzify`で校正した。ただし、入力例・解析結果・辭書見出しの引用は原表記を保存する。

```text
思う・思わない・思います・思えば・思おう
  → 思ふ・思はない・思ひます・思へば・思はう
思える・思われる・思わせる
  → 思へる・思はれる・思はせる
植える・植えない・植えよう
  → 植ゑる・植ゑない・植ゑよう
用いる・用いた
  → 用ゐる・用ゐた
```

「思った」「思って」「問うた」の音便は保存する。「考える」を「考ふ」にするやうな文語化はしない。旣に「思ふ」「考へる」「植ゑる」となってゐる箇所は再生成しない。

## 判定と原文の保存

埋込みUniDicの品詞・語彙素・讀み・書字形基本形・活用型・活用形を照合する。登錄された漢字表記の動詞だけを對象とし、確認できた送り假名だけを書換へる。かなだけの「いる」などから語義を推測しない。

正字は解析用の寫しで新字へ正規化する。語境界處理と同じ`dic/unidic_normalization.tsv`と原文位置の對應を使ひ、原文の漢字・空白・改行は保存する。解析に失敗した場合や、對應しない品詞・語形はこの段階では變へない。

名詞・複合動詞・未登錄語への一般化は行はない。たとへば名詞「思い」を新たに「思ひ」へ直す處理は含めない。UniDicが「考えよ」を「考え／よ」、「考えさせる」を「考え／さ／せる」と名詞に解析する場合も、この段階では推測して補はない。ただし旣存のかな置換は後續で適用されるため、從來の名詞・定型句などの變換は維持される。

報吿の形式・CLI option・終了statusは變更しない。未登錄語や解析の曖昧性を新たに報吿する機能は含まない。URL・code・引用を保護する機能も追加してゐない。

## 語彙data

`dic/verb_kana.tsv`を實行fileへ埋込む。32表記を登錄し、各行は次の6欄である。

1. UniDicの語彙素。
2. 語彙素の讀み（UniDicの`lForm`。表層形の發音ではない）。
3. 現代の活用型。
4. 變換を認める現代表記の書字形基本形。
5. 同じ漢字表記のまま、かなだけを歷史的表記にした基本形。
6. 出典。

解析用の鍵は新字で記錄する。出力の正字化は別段階が擔ふ。「喩える」「譬える」の語彙素は「例える」であり、語彙素と表記を混同しない。

- 五段ワア行で歷史的ハ行の語は、未然・連用・終止・連體・假定・命令・意志推量の各形を共通規則で扱ふ。促音便・ウ音便は變へない。
- 同じ語彙素と讀みを持つ可能形は、基本形が登錄語の語幹＋「える」であり、下一段ア行の場合だけ「え → へ」を適用する。
- 下一段ア行は語別に「え → へ」または「え → ゑ」を指定する。上一段ア行は「い → ゐ」を指定する。似た活用型の「見える」「覺える」「燃える」などへ一律には適用しない。

28表記は旣存の`kana_replacements.tsv`の對應を引繼いだ。新規の4表記は、コトバンク所收の大辭泉・精選版日本國語大辭典の見出しを確認した。

- [思う](https://kotobank.jp/word/%E6%80%9D%E3%81%86): 「おもふ」、ワ行五段（ハ行四段）。
- [買う](https://kotobank.jp/word/%E8%B2%B7%E3%81%86): 「かふ」、ワ行五段（ハ行四段）。
- [植える](https://kotobank.jp/word/%E6%A4%8D%E3%81%88%E3%82%8B): 「うゑる」、ワ行下二段に對應。
- [傳える](https://kotobank.jp/word/%E4%BC%9D%E3%81%88%E3%82%8B): 「つたへる」、ハ行下二段に對應。

dataを追加する際は、出典の表記とUniDicの解析を確認し、正かなづかひ・同音異語・音便を含むtestを追加する。現在の實裝が扱へない活用型、不整合な基本形、かなだけの表記、重複する鍵は初期化時にerrorにする。變更したdataのSHA-256を`dic/MANIFEST.json`にも反映する。

## 檢査

```sh
make test
cargo test --locked
cargo fmt --check
cargo clippy --locked --all-targets -- -D warnings
bb scripts/verify_dic_manifest.clj
cargo run --locked -- --report none tests/fixtures/verb-kana.txt
cargo run --locked -- --check --report none tests/fixtures/verb-kana-expected.txt
```

單體testでは全登錄基本形を旣存の文字列置換に賴らず檢査する。活用形・可能・受身・使役・音便・正字との混在・異なるUTF-8 byte長・不正なdata・對象外語を檢査し、CLI testでは實際の出力と`--check`の終了statusを確認する。
