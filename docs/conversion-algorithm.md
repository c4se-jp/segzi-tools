# 正字・正かなづかひ變換のalgorithm

`segzify`は、埋込み辭書の置換規則とUniDicによる形態素解析を組み合はせ、入力の表記を順次變換する。文意を完全に理解して正しい表記を保證するものでも、口語を文語に翻譯するものでもない。辭書の收錄範圍と解析結果によって、變換されない語や、文脈に合はない變換があり得る。

## 處理の順序

各段階は前の段階の結果を入力とする。置換規則は順に適用されるため、ある規則の出力が後の規則で更に變換されることがある。

1. 中國語由來の熟語を、語境界を調べずに置換し、續いて中國語由來の單字を置換する。
2. 文化廳「同音の漢字による書きかへ」に由來する、自動置換しない候補を、この時點のtextから檢出し、報吿に記錄する。
3. 一般の熟語と「同音の漢字による書きかへ」に由來する自動置換規則を、語境界を考慮して適用する。
4. 登錄された動詞の活用形について、送り假名を正かなづかひにする。
5. 單字を正字に置換する。
6. かなを含む文字列を置換し、續いて正規表現による置換を行ふ。
7. 最終出力に殘る曖昧字を數へ、候補と共に報吿する。

熟語規則は置換元の長いものを先に適用する。ただし一般の熟語規則と「同音の漢字による書きかへ」に由來する自動置換規則は別々に長さ順とし、一般の規則を先に適用する。かなの文字列置換と正規表現による置換は、それぞれ辭書の記載順に適用する。これは全規則を一度に最長一致させる處理ではない。

## 語境界と熟語

熟語の境界判定にはUniDicを使ふ。解析しやすい樣、正字を含む入力から解析用の寫しを作り、その文字位置を變換對象のtextに對應させる。寫しの正規化は出力そのものの變更ではない。熟語規則ごとに、その規則を適用する時點のtextを解析するため、先行する置換が後續の境界判定に影響し得る。

熟語の一致箇所は、始點と終點の**兩方が語境界**なら置換する。複數の解析語にまたがってゐても、兩端が境界なら對象となる。

兩端が揃はない場合は置換しない。そのうち一致箇所の內部に語境界がないものは、一つの解析語の一部分として見送った候補を報吿する。內部に語境界があるものは報吿しない。解析に失敗した場合はtextの先頭と末尾だけを境界として扱ふ。

「同音の漢字による書きかへ」に由來する自動置換しない候補は、兩端が語境界に一致する場合に報吿するが、その候補としては置換しない。候補の分類と保守は[文化廳置換表の保守](bunka-replacement-review.md)を參照。

## 動詞の正かなづかひ

動詞の處理は、形態素解析結果の品詞・語彙情報・活用情報と、登錄された動詞の表記を照合する。一致し、對應する活用形が確認できた場合に、送り假名を置換する。例へば「思います → 思ひます」「植える → 植ゑる」とし、「思った」のやうな音便は保存する。

かなだけの表記から語義を推測せず、未登錄語に規則を一般化しない。解析失敗や對應しない語形はこの段階では變へないが、後續の文字列置換に一致すれば變はり得る。對象となる活用型、例及び辭書の保守は[動詞の活用と正かなづかひ](verb-kana.md)を參照。

## 報吿と限界

報吿は、次の異なる時點の觀測をまとめたものである。

| 報吿 | 調査時點と內容 |
| --- | --- |
| `unresolved_bunka_replacements` | 中國語由來の置換後、語境界に一致した「同音の漢字による書きかへ」由來の候補 |
| `boundary_skipped_compound_replacements` | 各熟語規則の適用時、一つの解析語の一部として見送った候補 |
| `unresolved_ambiguous_characters` | 全置換後の出力に殘る曖昧字と候補 |

報吿は利用者の確認を助けるものであり、誤變換や未變換の網羅的な檢出ではない。特に、語境界により見送った一致のすべてを報吿する譯ではない。また、URL・code・引用を特別に保護しないため、その內部にも置換が適用され得る。

`--check`は變換結果と入力との差を檢査し、`--fail-on-unresolved`は上記の報吿がある場合に失敗とする。optionと終了statusの詳細は[使用法](../README.md#使用法)を參照。

## 本文の保守

變換段階の順序、語境界の判定、動詞の對象範圍、報吿の意味又は制限を變へる際は、相關するtestと共に本文を確認し、利用者に見える振舞ひの變更を反映する。個々の辭書項目や實裝手法は本文に列擧せず、詳細は各辭書・source・專門文書を正とする。
